# SIMS Doctor Site Diagnosis v0.5.0 Sprint 4.1

## Why
Real Doctor output used the correct top-level format
`SIMS_DOCTOR_SITE_WIDE_RESULT_V1`, but returned a practical triage structure
instead of the canonical `diagnosis_cases[]` array.

## Fix
- Accept both canonical `diagnosis_cases[]` and the Doctor's actual triage shape.
- Automatically convert:
  - priority_queue_for_precision_diagnosis
  - content_gap_merged_into_existing_theme
  - sbm_routine_queue_high_confidence_standalone
  - low_priority_monitor_medium_confidence_single_query
  - creator_candidates_pending_cannibalization_check
  into canonical treatment-plan cases.
- Enrich case IDs from the existing Site-wide diagnosis case sheet.
- Accept the full Doctor response text or JSON.
- Referral explicitly tells Doctor NOT to instruct the user to paste into SBM.
- Referral includes a canonical result schema example.

## Protected
No changes to RC5 health diagnosis, Treatment Batch, individual Case Package,
opportunity detection/clustering, Site-wide Case IDs, or request_id.
