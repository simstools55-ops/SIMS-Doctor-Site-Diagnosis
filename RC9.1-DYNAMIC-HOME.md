# RC9.1 Dynamic Diagnosis Home

Home is now the primary operating screen.

It displays:
- Current site / Evidence
- Overall diagnosis status
- Site-wide analysis counts
- Diagnosis comment
- Next action
- Why Diagnosis chose that action
- Exact menu path

Routing principle:
- Cross-article signals (cannibalization / new-article opportunity / content gap) -> site-wide Doctor diagnosis
- Article-specific candidates without cross-article signals -> individual precision diagnosis
- Doctor NEEDS_EVIDENCE -> additional evidence / precision diagnosis
- Doctor WRITER / MERGE / CREATOR -> treatment plan / handoff

The user should not decide whether site-wide diagnosis is needed.
