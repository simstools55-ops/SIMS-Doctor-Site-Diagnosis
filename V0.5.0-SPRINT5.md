# SIMS Doctor Site Diagnosis v0.5.0 Sprint 5

## Purpose
Generate full-Evidence precision packages only for Doctor-prioritized site-wide clusters.

## Selection
Only canonical result cases where:
- route_to = NEEDS_EVIDENCE
- doctor_decision = ADDITIONAL_EVIDENCE_REQUIRED
- maximum 5 clusters

## Evidence per article
- ArticleID / title / URL / main query
- Full article HTML
- Page summary evidence
- Page weekly evidence
- Top query evidence (up to 20)

## Package
One ZIP preserving all priority clusters:
- manifest.json
- DOCTOR-PRECISION-REFERRAL.md
- clusters/<cluster>/cluster.json
- clusters/<cluster>/articles/<article>/evidence.json
- clusters/<cluster>/articles/<article>/article.html

## Protected
No change to RC5, Treatment Batch, individual Case Package, site-wide detection,
Doctor result registration, stable Site-wide Case IDs, or request_id.
