# RC9.3 Guided Next Action

Primary operation:
`▶ 次に進む（Diagnosisに任せる）`

Diagnosis decides:
- No Evidence -> open Evidence picker
- Evidence only -> run site diagnosis
- Cross-article signals -> build/export site-wide Doctor workflow
- Individual priority articles -> auto-select and prepare precision diagnosis
- Missing Article Master -> stop and explain exactly what to import
- Enrichment incomplete -> save progress and resume with the same action
- Doctor result NEEDS_EVIDENCE -> create additional precision Evidence
- Treatment routes determined -> open treatment plan

Users do not select rows when Diagnosis already knows which articles require precision diagnosis.
