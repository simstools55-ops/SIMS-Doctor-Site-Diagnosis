# SIMS Doctor Site Diagnosis v0.5.0 Sprint 1.2

## Purpose
Second-stage diagnosis-case clustering.

## Changes
- Adds a parent-theme layer above query-intent clustering.
- Error codes and generic modifiers are removed when building a parent-theme key.
- Cannibalization cases can merge when article sets overlap and parent themes match.
- New-article/content-gap cases still require the same lead URL, but use parent-theme similarity.
- `サイト改善プラン` displays the parent theme.

## Expected regression
NHK Plus error-related rows such as error-code queries should collapse into a smaller number of meaningful diagnosis cases, while unrelated topics such as lion-dance honorarium queries remain separate.

## Protected scope
No changes to RC5 health diagnosis, Treatment Batch, Case Package, resumable processing, Case Identity, or request_id.
