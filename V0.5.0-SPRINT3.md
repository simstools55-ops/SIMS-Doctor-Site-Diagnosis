# SIMS Doctor Site Diagnosis v0.5.0 Sprint 3

## Purpose
Export the site-wide diagnosis cases as one Doctor package.

## Added
- `SiteWideDoctorPackage.gs`
- Menu 11: `サイト横断Doctor Packageを生成`
- ZIP contains:
  - `manifest.json`
  - `DOCTOR-REFERRAL.md`
  - `cases/<case-id>/case.json`

## Design
- One ZIP preserves the site-wide context.
- 40 cases are not exported as 40 independent user workflows.
- Doctor is explicitly instructed to evaluate shared causes and site structure.
- No automatic treatment is performed.

## Protected
No changes to RC5 health diagnosis, Treatment Batch, individual Case Package,
resumable processing, Case Identity, or request_id.
