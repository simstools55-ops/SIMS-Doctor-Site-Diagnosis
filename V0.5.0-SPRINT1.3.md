# SIMS Doctor Site Diagnosis v0.5.0 Sprint 1.3

## Purpose
Add a third clustering layer: Diagnosis Theme.

Flow:
query -> parent theme -> diagnosis theme

## Changes
- Uses article titles as semantic anchors for diagnosis-theme grouping.
- Error-code-only themes can merge into a broader product/service diagnosis theme.
- Cannibalization cases can merge when topic similarity is high and article sets overlap.
- New article/content-gap cases use the same diagnosis-theme layer while preserving destination boundaries.
- `サイト改善プラン` displays `診断テーマ`.

## Expected regression
NHK Plus error-related parent themes should consolidate further into a smaller number of Doctor cases, while unrelated topics remain separate.

## Protected scope
No changes to RC5 health diagnosis, Treatment Batch, Case Package, resumable processing, Case Identity, or request_id.
