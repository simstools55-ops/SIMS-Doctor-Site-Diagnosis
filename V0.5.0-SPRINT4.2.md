# SIMS Doctor Site Diagnosis v0.5.0 Sprint 4.2

## Root cause addressed
Long Doctor responses were being pasted into Spreadsheet UI `prompt()`.
That flow suspends Apps Script execution and is unreliable for large multi-line results.

## Fix
- Removes prompt-based long-text input from the site-wide result registration flow.
- Adds user-facing `Doctor結果取込` sheet.
- User pastes the full Doctor response into column A from A2 downward.
- Menu 12 reads the sheet and registers the result without suspending execution.
- Supports text split across multiple rows after paste.
- Keeps pasted content if registration fails.
- Adds stage diagnostics:
  - START
  - EXTRACT_JSON
  - VALIDATE
  - NORMALIZE
  - STORE_RAW_RESULT
  - WRITE_TREATMENT_PLAN
  - COMPLETE
- Failure dialog now shows the exact stage and exception message.

## Protected
No changes to RC5 health diagnosis, Treatment Batch, individual Case Package,
site-wide opportunity detection/clustering, stable Site-wide Case IDs,
Doctor Package V2, or request_id.
