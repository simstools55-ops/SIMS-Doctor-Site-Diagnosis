# SIMS Doctor Site Diagnosis v0.5.0 Sprint 2

## Purpose
Convert Site Improvement Plan findings into durable site-wide diagnosis cases.

## Added
- `サイト横断診断案件` user sheet.
- Stable `SITE-OPP-*` case IDs derived from type + diagnosis theme + target URLs.
- Explicit route and purpose for Doctor review.
- Menu 9: create site-wide diagnosis cases.
- Menu 10: open site-wide diagnosis cases.

## Routing
- Cannibalization -> Doctor -> Merge/Writer if needed.
- Content gap -> Doctor -> Writer/Creator decision.
- New article opportunity -> Doctor -> Creator after duplication/cannibalization check.

## Not included yet
- Doctor ZIP export.
- Automatic Merge/Writer/Creator execution.
- Any article modification.

## Protected
RC5 health diagnosis, Treatment Batch, individual Case Package,
resumable processing, Case Identity and request_id are unchanged.
